# Parche Dev 2026

Sitio oficial del encuentro Parche Dev 2026, construido solo con HTML semantico. Reto individual del Modulo 1 · HTML y CSS, RIWI.

Sitio publicado: https://bsycruz.github.io/parchedev/index.html

## Paginas

- Inicio
- Agenda
- Ponentes
- Inscripcion y confirmacion
- Codigo de conducta

## Como verlo en tu computador

1. Clona el repositorio.
2. Abrelo en VS Code.
3. Abre index.html con Live Preview.

## Decisiones que tome

- En "Lo que vas a encontrar" use `ul` y no `ol` porque el orden no importa son cosas que hay en el evento y no pasos.
- En el indice de "En esta pagina" del codigo de conducta si use `ol` porque sigue el orden en que aparecen las secciones en la pagina.


## Lo que aprendi

- A hacer tablas con `caption`, `scope`, `colspan` y `rowspan` y que el validador me diga si me sobra o me falta una celda.
- Que el atributo `alt` sirve para los lectores de pantalla, para cuando la imagen no carga y para Google.
- A publicar un sitio en GitHub Pages.
- Lo que mas aprendí que no lo sabia en absoluto fue utilizar `https://validator.w3.org/nu/` me pareció una super herramienta para validar el HTML y me ayudo a mejorar mucho el sitio, siento que era algo que me faltaba para poder mejorar mis proyectos.
- Tambien sobre la metodologia de SEO, es algo que siento que se pasa por encima.
